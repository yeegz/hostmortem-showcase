A flight recorder for Linux.

When a gateway goes down and someone reboots it, the minutes before the fault matter. Hostmortem records kernel, network and service events to disk so you can see what happened.

Install

Ubuntu 22.04 / 24.04, Debian 12 / 13, or Raspberry Pi OS (64-bit). amd64 and arm64. Requires sudo.

curl -fsSL https://github.com/yeegz/hostmortem/releases/latest/download/install.sh | sudo sh

The installer verifies the package, starts hmd and keeps your evidence on upgrades.

  1. sudo hm drillRecord a test incident
  2. sudo hm explain 1Read the diagnosis
  3. sudo hm reportExport every incident as HTML

How it records

  1. Watches five places

    procfs counters, link and route changes over rtnetlink, the kernel log, a few active probes, and the processes you name.

  2. Commits events to disk

    One writer commits batches to SQLite in WAL mode. If something is dropped under load, the drop itself is written down.

  3. Keeps events in order

    Boot order first, then the kernel’s boot clock. Wall time is only for display, because edge boxes often wake up in 1970.

  4. Scores each explanation

    Twelve playbooks score evidence for and against. If two explanations tie or nothing qualifies, the answer is “unknown”.

Lab and install results

Lab, throughput and durability: an Ubuntu 24.04 arm64 container on an Apple M1 Pro. Install and memory: the installed service on fresh Debian 12 and Ubuntu 22.04/24.04 VMs, amd64 and arm64. Raspberry Pi hardware testing is pending.
