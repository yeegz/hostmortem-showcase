Lab incident reports

Each file is the unedited output of hm explain --html from the real-fault lab (13–14 November 2026). Self-contained, no scripts.

  • Upstream DNS down: iptables drops UDP 53 at the upstream DNS server for 20 s.
  • Local resolver broken: resolv.conf on the box points at a dead stub for 20 s; the upstream server is fine.
  • Cable pulled: The box’s network interface is taken down for 20 s, then brought back.
  • kill -9: A watched process is killed with SIGKILL. Nothing else changes.
  • kill -9, kernel log hidden: The same kill, but the agent runs without CAP_SYSLOG and CAP_SYS_ADMIN, so it cannot read the kernel log.
  • 50% packet loss: tc netem drops half the packets from the gateway for 30 s.
  • Latency spike: tc netem adds 300 ms ± 50 ms of delay at the gateway for 20 s.
  • Agent killed mid-incident: During a DNS outage the agent itself is SIGKILLed, restarted 3 s later, and keeps the same incident.
  • Out of memory: A process in a cgroup capped at 64 MiB allocates until the kernel's OOM killer ends it.
  • CPU starved: Twelve busy loops on four vCPUs for 30 s.
  • Crash-restart loop: A watched service is killed with SIGKILL and restarted four times in about 20 s.
